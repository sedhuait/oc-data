missing field is a task, and a wrong field is a broken promise.

or the document in front of them — not code.

## The two gaps worth most

**Ingredient lists.** The fact people trust most, and the one brands publish as an
image so nobody can search it. Typing one off a pack, in declared order, is the
single most valuable contribution to this dataset.

| Domain | Records with no ingredient list |
|---|---:|
| grocery | 7,878 |
| beauty | 1,813 |

**Barcodes.** A GTIN is how a record matches a listing on any shop. Without one,
a product can only be matched by name, which is guesswork.

| appliances | 602 |
| phones | 430 |
| grocery | 210 |
| printers | 98 |
| networking | 97 |

## How to fill one in

1. Find the record: `grep -rn "<product name>" products/`
2. Add the field to `attributes`, and a source with today's date saying where you read it
3. If the category's required fields are now all present, change `"status"` to `"entry"`
4. `npm run format && npm run validate`, then open a pull request

Never guess. If the pack is unreadable or the PDF cell is merged, leave it — a gap
is a task for the next person, and a wrong number is worse than no number.
